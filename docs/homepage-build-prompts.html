로컬 실행

PROMPT 1

  • 브라우저에서 3D 랜딩페이지가 열림
2

홈페이지 고도화 요청

PROMPT 2 
현재 페이지를 고도화해서 홈페이지(다중 페이지)를 만들 거야. 아래와 같이:

추가 페이지 회사소개, 제품소개, 게시판 생성하고
회원가입/로그인 페이지(구글 로그인) 생성하고
권한관리 RBAC(마이페이지 / 관리자페이지) 보안에 신경 써서 내 계정의 슈파베이스를 활용해줘.
결제 시스템은 토스페이먼츠 결제 테스트가 잘 될 수 있도록 해줘!
마지막으로 앞으로 유지보수를 용이하게 할 수 있도록 폴더와 파일을 기능별로 분리해서 작업해줘!
완성이 되면 검수 - 보안 - 점검 - 디버깅 - 완료가 될 때까지 작업해.

AI가 Supabase 프로젝트와 관리자 계정, 토스 테스트 상점 여부를 물어봅니다. 아래처럼 답합니다.

답변 
슈파베이스는 로그인해놨으니 컴퓨터유즈를 사용해서 직접 연동해줘. 내 구글 계정은 내이메일@gmail.com이야.
토스 테스트 상점 있음. 199,000원 단일 상품으로 진행해줘.
  • 계획 설명 후 페이지·권한·결제 코드와 테스트 작성 시작
3

Supabase 프로젝트 지정

PROMPT 3 
슈파베이스 프로젝트 https://프로젝트ID.supabase.co 여기에 연동해줘
  • Supabase 대시보드 Table Editor에 회원·게시판·주문·감사 기록 테이블 생성
  • 다른 프로젝트에 연결했다고 하면: 프로젝트ID 여기다 해달라니까 슈파베이스
4

결제 테스트 금액

PROMPT 4 
상품 결제 테스트를 위해서 현재 상품 금액을 100원으로 변경해줘
  • 제품 화면·주문·결제 승인·DB 금액이 모두 100원

현재 깃허브에 푸시하지 말고 새로운 깃 레포를 생성해서 따로 저장해줘
  • 기존 랜딩페이지 저장소는 그대로, 새 저장소 3D-homepage 생성
6

Vercel 새 배포

PROMPT 6 
버셀로 새로 배포하고 슈파베이스랑 토스 결제랑 로그인 권한관리, 마이페이지, 관리자 페이지가 잘 실행될 수 있게 해야 된다!
  • 새 Vercel 프로젝트 생성, 환경 변수 등록
  • 배포 주소가 Supabase 로그인 리다이렉트와 토스 성공·실패 주소에 반영
7

별점·사진 리뷰

PROMPT 7 
추가로 상품 리뷰는 별점과 텍스트, 이미지를 남길 수 있도록 해줘!
  • 회원당 리뷰 1개, 사진 최대 3장, 작성자만 수정·삭제
8

Google 로그인 완료

PROMPT 8 
Google 로그인 설정도 끝까지 완료해줘
  • Google Cloud OAuth 클라이언트 생성 (생성 버튼 확인 요청 시 승인)
  • Supabase Authentication → Providers → Google 활성화
  • 내 Google 계정으로 실제 로그인 성공, 관리자 권한 적용

Google 리다이렉트 URI는 https://프로젝트ID.supabase.co/auth/v1/callback 입니다.

제품소개에 3D 모델

PROMPT 9 
제품소개에 상품은 이미지 말고 3D를 그대로 가져와서 동작되게 동일하게 해줘. 이미지는 너무 심심해.
  • 제품소개 페이지에서 드래그 회전·확대·분해·색상 변경 동작

관리자 페이지

PROMPT 10

  • 배포주소/grok/admin/에서 회원 역할·주문·감사 기록 조회

토스 결제 테스트
