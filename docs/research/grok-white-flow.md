# 화이트 스크롤 랜딩 — 최종 방향 (2026-09-09)

기존 고정 화면에서 문구만 교체하던 방식은 사용자 요청에 따라 교체했다.

- 전체 흰 배경, Pretendard Bold(700)와 Thin(100)만 사용. 폰트는 public/fonts/pretendard에 자체 제공하며 SIL OFL 라이선스를 동봉했다.
- 원본 히어로의 3D 회전, 분해, 키 피드백, 볼륨 노브를 유지하고 장식 문구·활동 패널을 제거했다.
- 디스플레이 → 볼륨 노브 → 키캡·LED → 내부 구조가 각각 독립된 문서 섹션이다. 설명은 문서 스크롤과 함께 위로 지나간다.
- `flow-motion.mjs`는 문서 위치에 따른 카메라, 좌우/상하 화면 좌표, 분해 값을 연속 계산한다. 하나의 스크롤용 WebGL 모델이 각 섹션의 위치를 따라간다.
- 모바일은 문구 위, 모델 아래로 배치한다. 화면 밖 섹션의 3D 렌더링을 중지한다.
- 색상은 Black, White, Silver만 제공. 실버는 금속도 1, 낮은 거칠기, 반사 강도를 적용한 유광 재질이며 키캡과 본체가 함께 바뀐다.
- 가격은 199,000원. 출시 알림은 이메일/동의 검증과 기기 내 저장·삭제가 가능한 프리뷰. 실제 수집 서버/메일 발송은 연결되지 않았으며 폼 안에 명시했다.

## 실행 및 검증
- 현재 개발 화면: http://localhost:3102/grok/
- `npm test`는 `src/features/product`에서 실행한다. 18개 테스트.
- 루트에서 변경 파일 ESLint 및 `npm run build`.
- 관련 기능: `landing/sales-landing.tsx`, `landing/flow-motion.mjs`, `product-scene.tsx`, `create-model.ts`.
- 이전 `scroll-story.mjs`는 상품 마감 선택의 정적 3D 프리뷰에 재사용한다. 본문의 주 스크롤은 `flow-motion.mjs`다.
# 후속 인터랙션

- 스크롤 소개 모델의 OrbitControls를 활성화한다. 드래그·방향키·확대 버튼·Ctrl+휠 조작 후 시점을 유지하고 다음 문서 스크롤에서 소개 카메라로 복귀한다.
- 일반 휠은 문서 스크롤에 사용한다. 확대/축소/소개 시점 복원 버튼을 별도로 제공한다.
- 원본 BSD 로고를 헤더에 사용한다. 11개 키의 컬러 링과 광원 번짐은 키 눌림 상태에 따라 함께 숨긴다.
- 실제 부품 경계 투영으로 검정 점선 박스/연결선을 배치한다. 볼륨 노브 이름표는 연한 회색 테두리를 사용한다.
