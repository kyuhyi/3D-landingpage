# GROK BOT 판매 랜딩 확장

## 확정 방향
- 기존 히어로 및 조작을 보존한다. 기존 사진·영상과 같은 짙은 메탈, 모노 라벨, 민트 포인트를 이어간다.
- 가격 199,000원. 주 전환은 구매 대신 출시 알림 신청.
- 히어로 아래: 가치 소개 → 스크롤 3D 부품 투어 → 사용 흐름 → 마감 선택/가격/알림 → FAQ.
- OLED 디스플레이, 볼륨 노브, 키캡/LED, 상판/스위치/PCB의 명칭을 실제 모델 좌표에 붙인다.

## 아키텍처와 하네스
- `features/product/landing/`: 콘텐츠, 스크롤 시퀀스, 출시 알림 UI를 분리한다.
- 기존 ProductScene을 재사용하고 스크롤 진행률 ref를 추가한다. 히어로의 자동 투어와 스크롤 투어 경로를 격리한다.
- 스크롤 구간에서 sticky 3D가 유지되며 카메라/분해 정도가 연속 보간된다. 화면 밖 렌더링은 기존 IntersectionObserver로 중단한다.
- 스크롤 캔버스는 휠/터치를 가로채지 않는다. 모바일에서는 모델과 설명을 상하 배치한다.
- 테스트 먼저: 진행률 경계/역방향 이동/장면 연속성/레이어 분해, 이메일 및 동의 검증.
- 검증: Node 테스트 → 변경 코드 ESLint/TypeScript/빌드 → 실제 브라우저 히어로, 스크롤 4개 구간, 폼 오류/저장/삭제, 모바일.

## 판매 콘텐츠의 사실 범위
- 가격 외 실제 제조 사양·배송·보증·호환성은 미확정. 수치나 후기를 임의로 만들지 않는다.
- 연결된 알림 수집 서버가 없으므로 이메일은 동의 후 이 기기에 저장하는 미리보기로 제공한다. 접수·메일 발송 완료로 표시하지 않는다.
- 실제 알림 서비스 연결 지점은 별도 설정으로 분리한다. 비밀키나 임의의 외부 수신 주소를 추가하지 않는다.
