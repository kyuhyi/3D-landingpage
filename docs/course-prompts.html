Claude Code는 프로젝트를 담을 빈 폴더에서 실행합니다.

1

PWA 전환과 APK 제작

저장소를 클론하고, 매니페스트·서비스워커·모바일 CSS를 넣은 뒤 Capacitor로 APK를 빌드합니다.

PROMPT 1 
https://github.com/아이디/저장소.git
현재 만들어진 3D 랜딩페이지를 내 안드로이드 폰안에 PWA방식으로 어플리케이션 제작을 하고 싶어!
모바일 최적화 해서 기존에 만들어진 랜딩페이지가 그대로 구현이 될 수 있도록 APK 파일로 제작해줘!
  • public/manifest.webmanifest, public/sw.js, public/icons/ 생성
  • android/ 폴더와 capacitor.config.ts 생성
  • android/app/build/outputs/apk/release/app-release.apk 빌드 성공
  • npm run check 통과

첫 Gradle 빌드는 의존성을 내려받느라 2~5분 걸립니다.

2

Vercel 배포와 HTTPS

PWA 설치와 서비스워커는 HTTPS에서만 동작합니다. 먼저 터미널에서 로그인합니다.

npx vercel login
PROMPT 2 
배포가 되지 않았으니 버셀에 배포한뒤에 https 적용후에 어플리케이션이 정상작동 할 수 있도록 해줘
PROMPT 3 · 로그인 후 
버셀 로그인했으니 배포 진행해줘
  • GitHub 저장소가 Vercel 프로젝트에 연결되고 main 푸시마다 자동 배포
  • https://프로젝트명.vercel.app 접속 시 랜딩페이지 표시
  • /manifest.webmanifest, /sw.js 주소가 200 응답
3

에뮬레이터 미리보기

Android Studio에서 가상 기기를 하나 만들어 두면 Claude가 APK를 설치해 화면을 보여줍니다.

PROMPT 4 
미리볼수 있도록 에뮬레이터를 띄워줘
  • 에뮬레이터 창에 BSD BOT 앱이 실행되고 3D 모델이 드래그로 회전
  • 스크롤 시 분해 뷰와 컬러 선택 섹션 표시

에뮬레이터 Chrome에 Google 로그인 화면이 뜨면 취소합니다. 비밀번호는 입력하지 않습니다.

4

폰에 설치

두 가지 방법 중 하나를 고릅니다.

방법절차
APK 직접 설치release/BSD-BOT-1.0-release.apk를 폰으로 전송 → 파일 열기 → "출처를 알 수 없는 앱" 허용 → 설치
USB 디버깅개발자 옵션에서 USB 디버깅 켜고 아래 명령 실행
PWA 설치폰 Chrome에서 배포 주소 접속 → 메뉴 → "홈 화면에 추가"
adb install -r release/BSD-BOT-1.0-release.apk
5

수정 후 다시 빌드

웹 코드를 바꾼 뒤 APK를 갱신할 때 씁니다.

npm run build
npx cap sync android
cd android && ./gradlew assembleRelease
PROMPT 5 
웹 코드 수정했으니 다시 빌드해서 APK 갱신하고 에뮬레이터에 재설치해줘

서명 키 android/keystore/는 잃어버리면 같은 앱으로 업데이트할 수 없습니다. 백업하고 git에 올리지 않습니다.
