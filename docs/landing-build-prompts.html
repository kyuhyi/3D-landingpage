기획

첨부: 제품 사진 + 로고
PROMPT 1 
나는 코딩을 처음 배우는 학생이야. 지금 연 빈 연습 폴더에서
첨부한 제품 사진과 BSD 로고를 활용해 3D 제품 홈페이지를 만들고 싶어.
완성된 저장소를 클론하거나 기존 프로젝트 소스를 가져오지 말아줘.
필요한 일반 개발 라이브러리는 설치해도 돼.
완성 목표는 다음과 같아.

- 전체 흰 배경, 웹페이지 글꼴은 Pretendard Bold와 Thin.
- 헤더에는 첨부한 BSD 로고, 첫 화면 제목은 BSD BOT.
- 사진 속 제품을 실제 입체 모델로 만들고 드래그로 돌려보기.
- 자동 회전, 확대·축소, 제품 분해·조립.
- 아래로 내려가면 디스플레이 → 볼륨 노브 → 키캡 LED → 내부 구조 소개.
- 소개 중에도 제품을 돌려볼 수 있고, 마지막 색상 선택 제품도 돌릴 수 있음.
- 상품 색상은 Black, White, Silver, Studio, Daylight, After hours.
- 색상을 바꾸면 모든 제품 화면에 같은 색상 적용.
- 가격은 199,000원, 버튼은 '출시 알림 신청'.

먼저 사진에서 보이는 부품을 정리하고, 만들 순서와 폴더 구성을 제안해줘.
사진에서 알 수 없는 내부 구조는 추정한 콘셉트라고 구분해줘.
꼭 필요한 질문이 있으면 먼저 물어봐. 아직 구현은 시작하지 마.
설명은 초등학생도 이해할 수 있게 짧고 쉽게 해줘.
  • 부품 목록, 제작 순서, 폴더 구성 제안이 나옴
  • 질문이 있으면 답하고 다음 단계로

  • package.json, AGENTS.md, CLAUDE.md 생성

기본 디자인

첨부: 로고
PROMPT 3 
홈페이지의 기본 디자인을 만들어줘.

- 배경은 페이지 전체 흰색.
- 첨부한 BSD 로고를 헤더 왼쪽에 원본 비율로 표시.
- 헤더 오른쪽에는 제품, 디테일, 출시 알림 메뉴.
- 첫 화면 메인 제목은 'BSD BOT.'
- 보조 문구는 '생각을, 손끝으로.'
- 웹페이지 글꼴은 Pretendard Bold 700과 Thin 100만 사용.
- 폰트 파일은 프로젝트에 보관하고 라이선스 파일도 함께 보관.
- 굵은 제목, 가는 설명, 넉넉한 여백. 불필요한 긴 문구는 넣지 않기.
- PC 첫 화면 오른쪽에는 나중에 사용할 제품 설정 영역을 확보.
- 휴대폰에서는 글자나 버튼이 잘리지 않게 배치.

먼저 로고와 글자, 제품이 들어갈 공간까지 만들고 브라우저에서 확인해줘.
아직 제품 대신 사진을 넣어 3D가 완성된 것처럼 표현하지는 마.
  • 흰 배경, 헤더 로고, BSD BOT 제목, Pretendard 글꼴

3D 모델 큰 모양

첨부: 제품 사진
PROMPT 4 
첨부한 제품 사진을 보면서 Three.js로 실제 3D 모델을 만들어줘.
평면 사진을 회전시키는 방식은 사용하지 마.

- 본체 위쪽으로 나오는 케이블과 모서리 나사.

본체 하판, 회로기판, 상판, 스위치, 키캡을 별도 그룹으로 나눠줘.
나중에 이 그룹들을 벌려서 내부를 보여줄 거야.
3D 코드와 화면 UI 코드는 파일을 나눠줘.
브라우저에서 실제 렌더링되는지 확인해줘.
  • 첫 화면에 3D 제품이 렌더링됨

세부 모양

PROMPT 5 
방금 만든 모델에 사진의 세부 모양을 추가해줘.

- 키캡 모서리는 둥글고 윗면은 부드러운 플라스틱처럼 표현.
- 노브 옆면에는 촘촘한 세로 홈.
- 디스플레이에는 작은 상태 글자와 움직임을 나타내는 그래픽.

  Approve, Pause, Voice, Orchestrate, New task 이름과 간단한 아이콘.
- 금속 본체에는 자연스러운 반사, 바닥에는 부드러운 그림자.
- 노브와 첫 줄 키 사이에 눈으로 구분되는 여유 공간.

모양을 확인할 수 있는 정면·위쪽·비스듬한 화면을 보여줘.

마우스 조작

PROMPT 6 
제품에 마우스 조작을 연결해줘.

- 드래그하면 좌우 360도 회전. 위아래 각도도 바꿀 수 있게.
- 놓으면 부드럽게 멈추기.
- 확대, 축소, 기본 시점, 위에서 보기, 정면에서 보기 버튼.
- 키보드 방향키로도 회전 가능.
- 일반 마우스 휠은 페이지 스크롤에 사용.
- Ctrl+휠과 확대·축소 버튼으로 제품 크기 조절.
- 너무 가까이 확대해서 모델 속으로 들어가지 않게 범위 제한.
- 휴대폰에서 세로 스크롤이 막히지 않게.

버튼을 누를 때 카메라 드래그까지 같이 발생하지 않도록 처리해줘.
코드 확인뿐 아니라 실제 브라우저에서 드래그와 확대를 확인해줘.
  • 드래그 회전, Ctrl+휠 확대, 일반 휠은 페이지 스크롤

키캡 눌림

PROMPT 7 
3D 키캡을 누르는 동작을 만들어줘.

- 누르고 있는 동안만 해당 키캡이 아래로 내려가기.
- 눌린 키 아래 LED 링과 빛 번짐은 함께 숨기기.
- 손을 떼면 키캡이 빠르게 원래 높이로 돌아오고 LED가 다시 보이기.
- 눌렀다 놓은 키가 계속 내려간 상태로 남지 않기.
- 같은 키를 여러 번 눌러도 작동.
- 키 밖에서 마우스를 놓거나 포커스가 바뀌어도 눌림 상태 해제.
- 클릭과 제품 회전 드래그를 구분.

선택한 키와 현재 눌린 키의 상태를 분리해줘.
눌림·해제 규칙은 먼저 테스트하고 실제 화면도 확인해줘.

LED 파스텔 색상

PROMPT 8 
키 아래 LED를 은은한 파스텔 색상으로 다듬어줘.

- 전체 11개 키에 민트, 연한 파랑, 크림, 라벤더, 연분홍 등을 배치.
- 선명한 무지개 네온처럼 보이지 않도록 채도를 낮추기.
- 얇은 LED 링과 아주 약한 주변 빛 번짐만 사용.
- 흰 배경에서도 색이 조금은 구분되게.
- 키를 누를 때 링과 번짐이 함께 숨는 동작 유지.

색상 출발값은 다음을 사용해줘.
#abd8cb, #b2bfdc, #dfd1a8, #ceb7dd, #aed1d9,
#bdb7d8, #d9b6c1, #dcc5ab, #b9d5bf, #b3cfdc, #cbbadb.
빛 번짐 불투명도는 0.25 정도에서 시작해서 실제 화면을 보고 조절해줘.
9

볼륨 노브

PROMPT 9 
볼륨 노브를 실제로 조작할 수 있게 해줘.

- 노브를 위쪽이나 오른쪽으로 드래그하면 음량 증가, 반대면 감소.
- 음량 범위는 0~100, 기본 음량은 65.
- 노브를 조작하는 동안 제품 전체가 함께 돌아가지 않기.
- 노브를 돌릴 때만 노브 테두리가 밝아지고 놓으면 은은하게 사라지기.
- 노브 윗면 전체를 하얗게 밝히지 않기.
- Sound on을 기본값으로 사용하고 끌 수 있는 버튼 제공.
- 키를 직접 누르면 짧고 작은 효과음 재생.
- 브라우저가 사용자 입력 전 소리를 막으면 첫 클릭 이후 재생.

히어로 오른쪽 설정 영역에 마감, 조명 강도, 분해, 음량을 세로로 배치해줘.
휴대폰에서는 조작 공간을 확보하도록 아래쪽 2열 배치로 바꿔줘.

6가지 마감 색상

PROMPT 10 
상품 마감을 총 6가지로 만들어줘.
아래 숫자는 본체 / 키캡의 색상 출발값이야.

- Black: #22282e / #20272c. 긴 가운데 키는 밝게 유지.
- White: #e8eae6 / #e5e9e5.
- Silver: #bec8d2 / #aebac5. 반짝이는 금속 재질.
- Studio: #4e595e / #626e74. 차분한 그레이.
- Daylight: #e9dfca / #f1e7d4. 따뜻한 아이보리.
- After hours: #4d465f / #706280. 은은한 퍼플.

Studio, Daylight, After hours는 상품 색상 이름으로 사용해줘.
히어로 위에 별도의 조명 프리셋 탭은 만들지 마.
우측 마감 선택 영역에 6개 색상 버튼과 선택한 색상 이름을 표시해줘.
마감 정의는 finishes.ts 한 파일에 모아줘.
선택한 색상 상태도 공통 부모 한 곳에서 관리해줘.
앞으로 추가할 스크롤 모델과 마지막 모델에도 같은 값을 전달할 거야.
색상 변경 시 본체, 키캡, 노브와 글자 대비를 함께 조절해줘.
  • 우측 패널에 색상 버튼 6개, 클릭 시 제품 색 변경
11

분해·조립

PROMPT 11 
분해 슬라이더와 분해·조립 버튼을 연결해줘.

- 0%는 조립된 상태, 100%는 층별로 벌어진 상태.
- 위에서부터 키캡 → 스위치 → 상판 → 회로기판 → 하판 순서가 보이게.
- 부품이 갑자기 튀지 않고 부드럽게 이동.
- 0%로 돌아오면 처음 위치와 정확하게 맞아야 함.
- 분해 상태에서도 드래그 회전과 확대 가능.
- 키캡의 작은 눌림 동작과 전체 분해 이동이 충돌하지 않기.

층의 위치 계산을 따로 분리해 테스트해줘.
완전 분해, 중간 상태, 재조립을 실제 브라우저에서 확인해줘.
12

자동 투어

PROMPT 12 
히어로 제품에 약 36초의 자동 투어를 만들어줘.
조립된 제품 소개 → 디스플레이와 노브 가까이 보기 → 다른 각도 보기
→ 내부 분해 → 다시 조립된 첫 장면 순서로 부드럽게 반복해줘.

- 처음 제목은 BSD BOT. / 생각을, 손끝으로.
- 자동 투어의 첫 소개 장면에서 제목을 보여주고 디테일 장면에서는 정리.
- 사용자가 제품을 드래그하면 자동 투어를 멈추기.
- 일시정지와 다시 재생 버튼 제공.
- 반복 끝과 시작에서 카메라가 갑자기 튀지 않기.
- 움직임 줄이기를 설정한 사람에게는 자동 움직임을 줄이기.
- 모델과 제목, 우측 설정 패널이 겹치지 않기.
13

스크롤 소개 4개 섹션

PROMPT 13 
히어로 아래에 실제로 세로로 이어지는 상품 소개 섹션 4개를 만들어줘.

1. OLED 디스플레이: '지금의 흐름을, / 한눈에.'
2. 볼륨 노브: '한 번의 회전. / 빛이 따라옵니다.'
3. 키캡 LED: '손끝의 감각. / 빛으로 돌아오다.'
4. 내부 구조: '안쪽까지, / 빈틈없이.'

중요한 동작:
- 각 섹션은 문서 아래에 실제로 존재하는 독립 영역이어야 해.
- 화면 하나에 고정한 채 문구만 교체하는 구성은 하지 마.
- 스크롤하면 이전 설명이 위로 올라가고 다음 설명이 아래에서 나타나게.
- 제품도 그 흐름을 따라 좌우와 위아래 위치가 바뀌고 시점이 전환되게.
- 마지막 내부 구조에서는 제품이 분해되게.
- 위로 스크롤하면 자연스럽게 이전 상태로 돌아가게.
- PC는 설명과 제품을 좌우로 번갈아 배치, 휴대폰은 설명 위·제품 아래.

스크롤 진행률과 카메라·제품 위치 계산은 별도 파일로 분리해서 테스트해줘.
렌더링 캔버스를 재사용해도 되지만 제품이 화면 가운데에 붙어 있는 느낌은 피해야 해.

소개 모델 조작과 부품 화살표

PROMPT 14 
아래 스크롤 소개 모델도 드래그 회전과 확대가 가능하게 해줘.

- 사용자가 돌린 각도는 손을 뗀 뒤에도 유지.
- 페이지 스크롤을 다시 시작하면 해당 섹션의 소개 시점으로 부드럽게 복귀.
- 일반 휠은 페이지 이동, Ctrl+휠과 +/- 버튼은 제품 확대·축소.
- '소개 시점으로' 버튼도 제공.
- 제목이나 버튼이 투명한 3D 캔버스에 가려 클릭되지 않는 문제 방지.

부품을 가리키는 설명 표시도 만들어줘.
- 부품을 둘러싸는 사각 점선 박스는 사용하지 않기.
- 바깥의 이름표에서 실제 부품을 향해 검정 점선 화살표 연결.
- 부품을 가리키는 화살촉만 빨간색으로 은은하게 점멸.
- 노브 이름표 테두리는 연한 회색.
- 회전·확대·분해해도 화살촉이 해당 부품을 따라가기.
- 움직임 줄이기 설정에서는 점멸을 멈추기.

카메라의 자동 제어와 수동 제어가 동시에 적용되지 않도록 처리해줘.

마지막 제품 선택과 출시 알림

PROMPT 15 
상품 소개 아래에 마지막 제품 선택 영역을 만들어줘.

- 제목은 '나의 데스크. / 나만의 색.'
- 왼쪽에는 드래그로 회전할 수 있는 제품.
- 오른쪽에는 199,000원, 6가지 마감 선택, '출시 알림 신청' 버튼.
- 색상을 바꿔도 돌려놓은 각도 유지.
- 히어로, 스크롤 소개, 마지막 제품이 항상 같은 색상을 사용.
- 화면 밖 모델에도 색상을 바로 적용해 이전 색이 잠깐 보이지 않게.
- 조명 강도도 공통 값을 사용해 같은 마감이 엉뚱하게 달라 보이지 않게.

출시 알림 버튼을 누르면 이메일과 동의를 입력하는 창을 열어줘.
지금은 실제 서버 연결 없이 이 브라우저에만 저장하는 연습용 UI로 만들어줘.
실제로 접수되거나 이메일이 발송됐다고 표시하지 말고,
'이 기기에만 저장되며 실제 접수·발송은 아직 연결되지 않았음'을 알려줘.
저장된 정보를 삭제할 수 있게 하고 잘못된 이메일도 확인해줘.
하단에 짧은 FAQ와 스크롤 중 보이는 출시 알림 버튼을 추가해줘.

최종 검사

PROMPT 16 
지금까지 만든 페이지를 최종 검사해줘.
PC 1280×800과 휴대폰 크기 390×844에서 다음을 확인해줘.

1. BSD 로고, BSD BOT 메인 제목, 전체 흰 배경, Bold/Thin 글꼴.
2. PC 우측 설정 패널, 휴대폰에서 잘리지 않는 조작 영역.
3. 제품 360도 회전, 확대·축소, 자동 투어, 분해·재조립.
4. 키 눌림 중 LED 숨김, 손을 떼면 복귀.
5. 노브 음량 조절과 테두리만 빛나는 동작, 기본 Sound on.
6. 은은한 LED와 검정 점선·빨간 화살촉.
7. 실제로 내려가는 네 소개 섹션과 수동 회전 후 스크롤 복귀.
8. 여섯 마감이 모든 제품 화면에 함께 적용되는지.
9. 마지막 제품의 회전과 출시 알림 입력·삭제.
10. 가로 넘침, 버튼 겹침, 브라우저 오류가 없는지.

오른쪽 스크롤바 모양은 숨겨도 페이지 스크롤 자체는 유지해줘.
화면 밖 3D 렌더링을 줄이고 페이지를 닫으면 자원을 정리해줘.
테스트, 린트, TypeScript 검사와 빌드가 실행되는 npm run check를 완성해줘.
실패하면 원인을 고치고 다시 확인해줘.
README에는 실행 방법과 아직 연결하지 않은 기능을 기록해줘.
검증 결과와 대표 화면을 docs에 남겨줘.
  • npm run check 통과
  • README.md, docs/ 검증 기록 생성
